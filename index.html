编辑信息

修改图片的标题、描述与标签，保存后立即生效。

图库管理

拖拽、粘贴或点击选择图片，填写信息后保存。改动将写入 gallery.json 与图片目录。

添加图片
点击选择图片，或把图片拖到这里
也支持 Ctrl / ⌘ + V 粘贴截图 · JPG / PNG / GIF / WebP / SVG
接口设置（GitHub 仓库）

填写后，上传/删除会通过 GitHub Contents API 直接提交到仓库，访客打开网页即可看到最新图片。
Token 仅保存在你自己的浏览器 localStorage 中，不会写入仓库。

主页背景
主页 Live2D 桌宠

进入编辑模式后，直接用鼠标拖拽桌宠即可调整它在首页的位置，工具条里还能切换表情、拖滑块改大小、开关表情随机展示（开启后和移动端一样自动随机切换）。电脑端与移动端各存一份、互不影响（想调手机上的效果请用手机打开本页）；设置只存本机浏览器，不写入仓库、无需重新部署。
